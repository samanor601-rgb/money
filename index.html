跨裝置即時同步 (Sam & Even)

只要兩人的手機使用相同的「家庭共享代碼」，在任一裝置記帳都會即時自動同步到另一台裝置！

Google 試算表連動整合

📌 3 步驟完成 Google 試算表自動同步：

  1. 打開您的 Google 試算表，點選上方選單 「擴充功能」>「Apps Script」。
  2. 清空編輯器內容，貼上以下程式碼並儲存：
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["ID", "日期", "成員", "類型", "分類/標的", "動作", "金額", "目前現值", "備註"]);
  }
  var data = JSON.parse(e.postData.contents);
  var rows = Array.isArray(data) ? data : [data];
  rows.forEach(function(r) {
    sheet.appendRow([r.id, r.date, r.member, r.type, r.name || r.category, r.action || "-", r.amount, r.currentPrice || "-", r.note || ""]);
  });
  return ContentService.createTextOutput(JSON.stringify({status: "ok"})).setMimeType(ContentService.MimeType.JSON);
}

3. 點擊右上角 「部署」>「新增部署作業」，類型選「網頁應用程式」，存取權限設為 「所有人」，部署後複製網址貼回上方欄位即可！
